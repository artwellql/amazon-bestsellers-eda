# Amazon Bestsellers: 

##  Description
An Exploratory Data Analysis (EDA) project focusing on Amazon's Top 50 bestselling books from 2009 to 2019. The main goal is to uncover business insights regarding book popularity, pricing strategies, user ratings, and genre trends (Fiction vs. Non-Fiction). This project demonstrates data manipulation, cleaning, and visualization skills.

##  Technologies
- **Language:** Python
- **Data Manipulation:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Environment:** Google Colab

##  Functionality
- **Data Cleaning & Preprocessing:** Handling missing values, standardizing column names, and preparing data for analysis.
- **Statistical Analysis:** Calculating key metrics such as maximum, minimum, mean, and median for book prices and user ratings.
- **Trend Analysis:** Investigating the distribution of book prices, tracking the number of bestselling fiction books over specific years, and identifying top-rated books.
- **Author Insights:** Discovering the most prolific authors in the bestseller list and analyzing their average ratings.
- **Visualizations:** Creating histograms for price distributions, bar charts for average prices by genre, scatter plots to understand the relationship between user ratings and reviews, and count plots for genre trends over time.
