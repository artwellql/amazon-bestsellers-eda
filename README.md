# Amazon Bestsellers: Data Analysis

**Overview**
This project explores a dataset of Amazon's Top 50 bestselling books to analyze pricing strategies and genre popularity. 

**Tech Stack**
* Python
* Pandas (Data manipulation)
* Matplotlib & Seaborn (Data visualization)

**Main Findings**
* **Genre Trends:** Non-Fiction books dominate the Top 50 and show a growing trend over recent years.
* **Pricing:** Non-Fiction books generally have a higher average price and a wider price range compared to Fiction.
* **User Engagement:** Fiction books get significantly more user reviews, even though Non-Fiction titles appear more often in the bestsellers list.

**How to Run**
1. Clone this repository.
2. Install requirements: `pip install pandas matplotlib seaborn`
3. Run the `amazon_bestsellers_eda.ipynb` notebook.
